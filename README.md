# Social Website UI Reference

Static social website pages and assets retained as a frontend reference project.

## Overview

- Static social website layouts
- Album and application download pages
- Bundled image and stylesheet assets

## View locally

Clone the repository and open `index.html` in a browser, or serve the repository through a local static web server. No dependency installation or build step is required.

## Scope

A collection of static UI reference pages, not the Laravel backend. See [LaravelSocialApp](https://github.com/AbdulSamadAhsan/LaravelSocialApp) for the application project. Preserve any bundled third-party asset notices.
